# 交互式智能体与 Copilot 规格 (AI Agent Specification)

## Purpose

AI Agent 交互式智能体核心能力在管理后台提供类对话交互式的助手，通过安全的工具注册表调度执行多步骤商品目录运维操作，严格校验管理员 ACL 权限，并对高危写操作引入人工介入确认机制。

## Requirements

### Requirement: 对话驱动的目录意图规划与执行
系统 SHALL 解析管理员提交的自然语言意图，规划多阶段执行步骤，并按需组合调用目录工具以完成指定业务任务。

#### Scenario: 交互式商品目录查询
- **当 (WHEN)** 管理员在对话框中输入“列出默认渠道下所有缺少描述文本的商品”时
- **则 (THEN)** `AgentRunner` SHALL 调度商品检索与概览工具，将结果格式化为包含商品直达链接的 Markdown 汇总报告

### Requirement: 工具安全注册表与细粒度权限校验
系统 SHALL 将可调用的目录操作统一收敛在 `ToolRegistry` 工具注册表中，并在调用任意工具前强制核验当前登录用户的后台 ACL 权限。

#### Scenario: 权限不足时拦截工具调用
- **当 (WHEN)** Agent 意图代表一位未被授予“新建商品”权限的操作员调用 `CreateProduct` 工具时
- **则 (THEN)** 系统 SHALL 立即阻断工具执行，并在对话界面提示用户缺少相应操作权限

### Requirement: 高危变更的人工二次确认保护
系统 SHALL 拦截大范围或破坏性的批量修改/删除行为，向操作员呈现变更预览并待显式授权后方可执行。

#### Scenario: 挂起批量修改并请求人工确认
- **当 (WHEN)** Agent 计划对 500 个商品的售价执行批量上浮调整时
- **则 (THEN)** 系统 SHALL 暂停直接写入，在对话界面中汇总展示待变更的影响范围与预览值，直至管理员点击“确认执行”按钮后才生效落库
