# AI 商品名称与名称模板

商品编辑页的 `[name]` 属性提供“名称模板”和“AI商品名称”快捷按钮，便于针对来自 1688 等货源平台的商品标题进行合规与吸引力提炼。

## 功能特性

1. **用途隔离**：提示词在 Magic AI → System Prompts 中以“商品名称优化”（`product_name`）用途进行独立维护与启停控制。
2. **负向过滤与去货源化**：
   - 严禁提及“厂家”、“工厂”、“源头工厂”、“直销”、“厂家直销”、“一手货源”、“批发”、“代发”、“加工”等货源或批发表述。
   - 过滤违禁词、价格金额与第三方电商平台名称。
3. **特性拓展与联想**：深度挖掘商品的实用特性、扩展功能、适用场景与消费者痛点解决方案，突出核心卖点。
4. **格式合规**：
   - 限制单行输出，去除多余换行与前后引号；
   - 推荐标题长度控制在 60 至 120 个字符以内。
5. **一键 AI 优化集成**：商品列表行与编辑页顶部的“AI 优化”按钮，会自动串联：**AI 商品分类 → AI 优化商品名称 → AI 优化商品描述**。
